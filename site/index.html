Fen
GitHub zoharbabin.com

A native Markdown editor that grows into a knowledge base.

Fen is a fast, native Markdown editor for Mac, iPhone and iPad. Write with a live preview. Open your folders as workspaces to search them by words and meaning, follow [[wiki-links]] and backlinks, and ask questions that come back with sources. Your notes stay plain .md files. Free and open source.

Signed and notarized by Apple, so it opens without Gatekeeper warnings. Needs macOS 15 or later (iOS 18 or later on iPhone and iPad).

What Fen does

A fen is a wetland that feeds itself. Your notes can work the same way: connected, searchable and always growing, while they stay plain files.

👀

Live preview, scroll-synced

GitHub-Flavored Markdown, syntax highlighting, MathJax and Mermaid render as you type. An optional Live Preview mode (Experimental) styles the source in place.

🗂️

Workspaces

Add as many folders as you like, with or without git. Fen lists their notes without opening each one, and writes nothing into your folders apart from an optional schema file.

🔎

Search by words and meaning

An on-device index finds notes by exact words and by meaning, across one workspace or all of them. Nothing leaves your Mac. The meaning side works for English.

🔗

Wiki-links and backlinks

Link notes with [[name]], [[name|text]] or [[name#heading]]. A backlinks list shows the notes that link here, even ones you have not opened.

🏷️

Document types

Define types and fields in a plain schema.yaml. Edit typed properties in the app. Hints flag a near-miss, and they never block a save.

💬

Ask your workspaces

Ask a question and get an answer that cites numbered sources with line numbers. A statement with no source gets a warning. Ask only reads.

🛡️

AI you control

Fen sends no AI request until you add a provider: Apple's on-device model, Ollama, or any OpenAI-compatible service. Each workspace sets what AI may see. Every AI edit goes through one gate and can be undone.

🤖

Ready for agents (Mac)

An optional MCP server listens on 127.0.0.1 only and is off by default. Each client gets its own token and its own workspaces. An agent commits to its own branch and your checkout stays put.

🔄

GitHub sync

Clone a repository as a workspace, then pull and push with a token limited to that repository, kept in the Keychain. On iPhone, Fen copies the repository through the GitHub API. Conflicts wait for your choice.

🕘

Version history

See the earlier versions the system keeps for a note. On iCloud, your other devices' recent versions show up too. We measured this between a Mac and an iPhone.

📱

iPhone and iPad

The same editor with keyboard shortcuts, a share sheet in and out, and one pane at a time on a narrow screen.

⚡

Native, free and open source

Pure Swift and SwiftUI on Apple Silicon. MIT license, no account, no telemetry. Every script ships inside the app.

Install

Mac: download

Get Fen.app.zip from the latest release, unzip it, and drag Fen to Applications. Choose Fen > Check for Updates… to update.

Mac: Homebrew

Install and upgrade with a tap.

brew tap zoharbabin/fen https://github.com/zoharbabin/fen
brew install --cask fen

iPhone, iPad and the Mac App Store

Fen is in App Review. One App Store listing will cover Mac, iPhone and iPad. Until it is out, use the Mac download above.

Build from source

Clone the repository and run swift build. The README has the steps.
